# Status Implementasi AIDSS

Satu-satunya sumber kebenaran tentang apa yang sudah ada dan apa yang belum. Kalau ada klaim tentang AIDSS di dokumen lain yang bertentangan dengan file ini, file ini yang benar.

Diverifikasi terhadap kode pada **2026-11-09**, setelah migrasi `0016` diterapkan. Cara verifikasi: setiap path file dan setiap nama endpoint yang disebut di bawah harus benar-benar ada, dan itu diperiksa oleh `backend/tests/test_docs_status.py`.
